# Application Insights Analysis – Power BI Project

## Project Overview
This project focuses on analyzing Application Insights data using Microsoft Power BI. It demonstrates the use of Power BI reporting and visualization capabilities to organize application related data and present meaningful metrics through an interactive report.

## Project Objectives
- Analyze application-related data.
- Monitor important application performance metrics.
- Present key performance indicators (KPIs).
- Explore trends and patterns in application data.
- Build an interactive Power BI report.

## Tools & Technologies
- Microsoft Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- Data Visualization
- Data Transformation
- KPI Reporting

## Project Files
- `App Insights PowerBI Report.pbit` – Power BI report template.
- `App Insights Analysis PowerBI Project.pdf` – Project documentation and report.

## Skills Demonstrated
- Data Analysis
- Data Cleaning and Transformation
- Power Query
- DAX Fundamentals
- KPI Reporting
- Data Visualization
- Dashboard Development

## Project Outcome
Created a Power BI report template for analyzing application-related information and presenting metrics through visual reporting.

## How to Explore
1. Download the Power BI report template.
2. Open the `.pbit` file using Power BI Desktop.
3. Configure the required data source if prompted.
4. Explore the report and its visualizations.

## Conclusion
This project demonstrates practical Power BI skills in data analysis, reporting, data transformation and visualization.
